# One Piece Animation & Ship Assets (`public/images/`)

Place your local animated GIFs or transparent PNGs in this folder (`digital-portfolio/public/images/`) using the exact filenames below:

1. **`thousand-sunny.png`** (or `.gif`)
   - **Used by:** `src/components/ShipBackground.jsx`
   - **Public URL path:** `/images/thousand-sunny.png`
   - **Recommended style:** Transparent-background PNG or GIF of the Thousand Sunny pirate ship.

2. **`going-merry.png`** (or `.gif`)
   - **Used by:** `src/components/ShipBackground.jsx`
   - **Public URL path:** `/images/going-merry.png`
   - **Recommended style:** Transparent-background PNG or GIF of the Going Merry pirate ship.

3. **`nami.gif`**
   - **Used by:** `src/components/NamiCompanion.jsx`
   - **Public URL path:** `/images/nami.gif`
   - **Recommended style:** Transparent-background GIF or character sprite of Nami waving, smiling, or holding her Log Pose / Clima-Tact.

4. **`chopper.gif`**
   - **Used by:** `src/components/ChopperMascot.jsx`
   - **Public URL path:** `/images/chopper.gif`
   - **Recommended style:** Transparent-background GIF of Tony Tony Chopper waving, bouncing, or dancing happily.

5. **`zoro-sanji.gif`**
   - **Used by:** `src/components/ZoroSanjiAnimation.jsx`
   - **Public URL path:** `/images/zoro-sanji.gif`
   - **Recommended style:** Transparent-background GIF or sprite animation of Roronoa Zoro and Sanji playfully clashing or arguing.

> **Note:** Until you drop custom image files into this folder, all components automatically display built-in custom animated SVG illustrations so the website never shows a broken image link. As soon as you add the files here, the website will automatically display them!
